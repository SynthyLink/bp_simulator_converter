# Experimental evidence

- [Orbital reproduction package](orbital/replay/README.md): the complete protocol,
  execution and analysis scripts, raw C#/browser results, source manifests,
  diagnostic controls and historical records. Start here to reproduce the
  reported orbital comparisons.
- [Historical orbital snapshots](orbital/README.md): original saved web pages,
  their provenance and a read-only archive check.
- [Trading](trading/README.md): recorded results and instructions identifying
  the source used for the trading comparison.

Applications live in `examples/`. The orbital package README specifies the exact
execution checkout and patch; its `SHA256SUMS.json` identifies the distributed files.
Preserve recorded data and provenance, and write new executions to a separate output
directory.

See the [paper version notice](../docs/paper/README.md) for the status of the
historical manuscript files retained in this repository.
