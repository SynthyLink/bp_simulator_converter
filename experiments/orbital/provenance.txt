Four original MHTML snapshots used for the comparisons in Table 5 of the main paper.
Files are unchanged except for their filenames. Each contains 91 C# server and 91 TypeScript client event records.
Compare state values by the displayed Loop index. TypeScript displayed times are one second later.
Duration values are milliseconds according to the historical timing implementations.
The exact source build used for the saved runs is not identified in the snapshots.
This archive contains saved outputs, not a new experiment or a guarantee of exact replay.
