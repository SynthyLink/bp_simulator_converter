Online Resource 2: Archived Orbital Outputs and Independent Reanalysis

Article: Backend-Frontend Converter: Component-Based Conversion of .NET Computational Models to TypeScript
Journal: SN Computer Science
Authors: Peter Ivankov; Max Shestov
Corresponding author: Max Shestov, Georgia Institute of Technology, Atlanta, GA, United States
Email: mshestov@gatech.edu

This resource contains four byte-identical historical MHTML snapshots, their original provenance record, a Node.js comparison script, per-event and summary results, and the original source-model screenshot at native resolution. The original-provenance.txt reference to Software and Systems Modeling is historical submission metadata.

Reproduction command from this directory:
node recompute-orbital-metrics.mjs . orbital-metrics.json

The analysis checks supplied hashes, aligns all 364 event pairs, and recomputes the manuscript's maximum and mean Euclidean position/velocity differences. All sixteen printed summary values and the stated tolerances are confirmed. It analyzes archived outputs rather than running either model.

The raw MHTML files, original provenance, and screenshot are preserved unchanged as documentary evidence; the article and journal metadata in this README apply to the complete resource.
